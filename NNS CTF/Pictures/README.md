# NNS CTF 2026: Challenge Screenshots
This folder contains screenshot proof-of-concepts and evidence artifacts for the challenges solved during the NNS CTF competition alongside team n00b_sec.

## **Completed Challenges Included:**
* **Web Hacker 2**: Parameter manipulation, BOLA/IDOR exploitation, and API traffic interception in Burp Suite.
* **Simon**: Client-side DOM modification and front-end restriction bypass via Developer Tools.
* **No Strings Attached**: Dynamic library tracing with `ltrace` capturing in-memory string comparisons.
* **Hiding in your WiFi**: Network traffic interception and ARP cache poisoning within a VXLAN container environment.
